# shanyraq

TypeScript-утилиты для Казахстана без зависимостей.

- **Проверка данных:** ИИН/БИН, телефоны и коды городов, IBAN и банки, госномера, регионы (КАТО).
- **Зарплата и пособия:** налоги с зарплаты, отпускные и больничный, расчёт при увольнении, декретные и пособие по уходу, пенсия, алименты.
- **Налоги и кредиты:** НДС, упрощёнка (910), налоговый календарь, пеня, налог на транспорт и имущество, регистрация и утильсбор, растаможка авто для физлиц, график кредита с ГЭСВ.
- **Суд и право:** процессуальные сроки, неустойка по ст. 353 ГК, госпошлина в суд, доли в наследстве.
- **Тексты:** сумма прописью, даты в документах, праздники и рабочие дни, казахская латиница.

[English](README.md) · [Онлайн-инструменты](https://shanyraq.webmonolith.kz) (81 страница на русском и казахском, работают на этом пакете)

- **Факты с источниками.** Каждое правило и справочник (`data/*.json`) ссылается на закон, приказ или реестр, откуда взято, с датой проверки. Что проверить не удалось, перечислено в `unverified` каждого справочника.
- **Маленький размер.** Большинство подмодулей ≤ 2 кБ gzip, модули с данными (банки, календарь, сроки, отпуска) — до 4 кБ; импортируйте только нужное.
- **Предсказуемость.** Чистые функции, без `throw` и глобального состояния. Парсеры возвращают `{ ok: true, value } | { ok: false, error }`.
- **Три языка.** Сообщения об ошибках и форматирование на русском, казахском и английском.
- **Всё рядом.** Схемы zod, генератор тестовых данных с seed и CLI.

> Статус: до первого релиза. В npm пакет пока не опубликован, до 1.0 API может меняться.

## Установка

```sh
npm i shanyraq
```

Node ≥ 18 или любой современный бандлер; есть сборки ESM и CommonJS.

## Примеры

```ts
import { parseIIN } from 'shanyraq/iin'
import { parsePhone, formatPhone } from 'shanyraq/phone'
import { parseIBAN } from 'shanyraq/iban'
import { moneyToWords } from 'shanyraq/money'
import { countWorkingDays, isDayOff } from 'shanyraq/calendar'
import { formatDate } from 'shanyraq/date'
import { toLatin } from 'shanyraq/translit'

parseIIN('900101 300126')
// { ok: true, value: { value: '900101300126', birthDate: '1990-01-01', gender: 'male', century: 20 } }

const r = parsePhone('8 (707) 123-45-67')
// { ok: true, value: { e164: '+77071234567', country: 'KZ', type: 'mobile', originalOperator: 'tele2-altel', ... } }
if (r.ok) formatPhone(r.value) // '+7 707 123 45 67'

parseIBAN('KZ86 125K ZT50 0410 0100') // банк определяется по коду: NBRKKZKX

moneyToWords(1234.5) // 'Одна тысяча двести тридцать четыре теңге 50 тиынов'
moneyToWords(1234.5, { lang: 'kk' }) // 'Бір мың екі жүз отыз төрт теңге 50 тиын'

isDayOff('2026-03-24') // true — Наурыз выпал на выходные, день перенесён
countWorkingDays('2026-03-01', '2026-03-31') // { ok: true, value: 18 }

formatDate('2026-10-22') // '22 октября 2026 года'
formatDate('2026-10-22', { lang: 'kk' }) // '2026 жылғы 22 қазан'

toLatin('Қазақстан Республикасы') // 'Qazaqstan Respublikasy'
```

Расчёты:

```ts
import { calculateSalary } from 'shanyraq/tax'
import { vacationPay } from 'shanyraq/leave'
import { loanSchedule } from 'shanyraq/loan'
import { claimPenalty } from 'shanyraq/claim'
import { inheritanceShares } from 'shanyraq/inheritance'

calculateSalary(500000) // ИПН 31 025, на руки 408 975, расходы работодателя 581 400
vacationPay(6000000, '2026-07-01', 24) // 17 рабочих дней × 24 390,24 = 414 634,08; 6 июля продлевает отпуск
loanSchedule(20000000, 7, 300) // 7-20-25: платёж 141 355,84, ГЭСВ 7,23 %
claimPenalty(1000000, '2026-01-31', '2026-10-01') // 243 дня по базовой ставке НБРК → 108 184,93
inheritanceShares({ spouse: true, children: 2 }, { estate: 30000000 }) // по 1/3 — 10 000 000
```

Функции возвращают `Result`; выше для краткости показано только `value`. Больше примеров (налоговый календарь, декретные, пенсия, транспорт, имущество, zod, faker, CLI) — в [README на английском](README.md#usage).

## Модули

| Подмодуль | Что делает |
| --- | --- |
| `shanyraq/iin` | ИИН: контрольная цифра, дата рождения, пол |
| `shanyraq/bin` | БИН: тип организации и подразделения, месяц регистрации |
| `shanyraq/taxid` | ИИН или БИН |
| `shanyraq/phone` | Номера +7: страна, мобильный оператор, город, форматирование |
| `shanyraq/iban` | IBAN Казахстана, справочник банков по коду и БИК |
| `shanyraq/money` | Сумма прописью (ru, kk), разбор суммы |
| `shanyraq/tax` | Зарплата 2026 (ИПН, ОПВ, ВОСМС, ОПВР, СО, ООСМС, СН), оклад ↔ на руки, НДС, МРП/МЗП, упрощёнка (910) |
| `shanyraq/deadlines` | Налоговый календарь: сроки сдачи и уплаты по режиму с переносом с выходных |
| `shanyraq/leave` | Отпускные, больничный, расчёт при увольнении (среднедневной заработок) |
| `shanyraq/family` | Декретные и выплата по уходу до 1,5 лет, пособия на рождение и уход |
| `shanyraq/pension` | Пенсионный возраст, базовая и солидарная пенсия, взносы в ЕНПФ |
| `shanyraq/alimony` | Алименты долей или в МРП, неустойка за просрочку |
| `shanyraq/loan` | Аннуитетный и дифференцированный график, досрочные погашения, ГЭСВ, предельные ставки |
| `shanyraq/procedure` | Процессуальные сроки (ГПК) |
| `shanyraq/claim` | Базовая ставка НБРК, неустойка по ст. 353 ГК, госпошлина в суд, налоговая пеня |
| `shanyraq/inheritance` | Доли наследников по закону, супружеская доля, обязательная доля |
| `shanyraq/vehicle` | Налог на транспорт, сбор за первичную регистрацию, утильсбор |
| `shanyraq/property` | Стоимость жилья для налога, налог на имущество, налог на землю |
| `shanyraq/customs` | Единый таможенный платёж за машину, ввезённую физлицом (решение ЕЭК № 107) |
| `shanyraq/calendar` | Праздники, выходные, расчёт рабочих дней |
| `shanyraq/date` | Официальные форматы дат (ru, kk), разбор |
| `shanyraq/translit` | Кириллица → латиница (алфавиты 2021 и 2018) |
| `shanyraq/plate` | Госномера (стандарт 2012+) |
| `shanyraq/regions` | Регионы с кодами КАТО и номеров |
| `shanyraq/i18n` | Сообщения об ошибках на ru, kk, en; объекты по модулям (`pensionMessages`, …) |
| `shanyraq/zod` | Схемы zod |
| `shanyraq/faker` | Валидные тестовые данные с seed |
