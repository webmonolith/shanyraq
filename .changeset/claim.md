Add `shanyraq/claim`: `baseRate(date)` (National Bank base rate since 1 April 2017), `claimPenalty(debt, due, until, options)` — penalty for using someone else's money under Civil Code art. 353 with partial payments and a creditor-chosen rate date, `claimDuty(price, options)` — state duty on money claims and court orders (Tax Code art. 665), and `taxPenalty(debt, due, until, options)` — penalty on late taxes and social payments at 1.25 × the base rate of each day (0.65 for horizontal monitoring), with partial payments (Tax Code art. 5 subp. 2).
